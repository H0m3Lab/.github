# Security policy

This policy applies to every repository in the H0m3Lab organization unless the repository has its
own `SECURITY.md`.

## Reporting a vulnerability

Please report security problems **privately**:

1. Open the affected repository on GitHub.
2. Go to the **Security** tab and choose **Report a vulnerability**.

Do not open a public issue, pull request, or discussion for a security problem.

Please include the version, how to reproduce it, and what an attacker could do. Never include real
credentials, even your own.

## What to expect

H0m3Lab is maintained in spare time, so there is no formal response time. We aim to confirm a report
within a week, keep you updated, and credit you in the release notes unless you prefer otherwise.

## Supported versions

Only the latest release of each project receives security fixes.

## Scope

H0m3Lab apps are designed for a home network or behind a reverse proxy you control. Reports about
running them directly on the public internet without HTTPS or authentication are still welcome, but
the fix may be documentation rather than code.
