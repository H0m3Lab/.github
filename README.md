# H0m3Lab/.github

Organization-wide files for [H0m3Lab](https://github.com/H0m3Lab):

- [`profile/README.md`](profile/README.md): the organization profile page
- [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`SECURITY.md`](SECURITY.md): defaults for every repository
- [`.github/`](.github/): default issue and pull request templates
- [`STANDARDS.md`](STANDARDS.md): how H0m3Lab repositories are set up
- [`templates/`](templates/): starting files for a new project (CLAUDE.md, CHANGELOG, CI, project metadata)
